# Vietnamese News Classification with PhoBERT v2

A Vietnamese news article classifier fine-tuned on **PhoBERT v2** (`vinai/phobert-base-v2`) that categorises articles into **10 topics** with a weighted F1-score of **91.86%** on the held-out test set.

The model is publicly available on Hugging Face: https://huggingface.co/longle0702/vietnamese-news-classifier-phobert

---

## Overview

This project fine-tunes [PhoBERT-base-v2](https://huggingface.co/vinai/phobert-base-v2) — a RoBERTa-based language model pre-trained specifically on Vietnamese text — for multi-class news article classification.

**Pipeline at a glance:**

1. `prepare_raw_data.py` pools all raw articles from `Train_Full/` and `Test_Full/`, applies Vietnamese text preprocessing, and writes a stratified **70 / 15 / 15** train / val / test split to `clean-data/`.
2. `prepare_data.py` loads the three pre-split folders into labelled Pandas DataFrames.
3. `train.py` fine-tunes PhoBERT-base-v2 with AdamW + linear warmup, early stopping, and best-checkpoint saving.
4. `main.py` runs inference on a single article from the command line.

## Usage

Follow these steps **in order** the first time you set up the project.

---

### Step 1 — Prepare raw data

> **Skip this step** if you already have `clean-data/` populated.

Place your raw articles (UTF-16 encoded, one file per article) inside category-named subdirectories:

```
Train_Full/<category>/<article>.txt
Test_Full/<category>/<article>.txt
```

Then run the preprocessing script from the **project root**:

```bash
python src/prepare_raw_data.py
```

This will:
- Pool all articles from both `Train_Full/` and `Test_Full/`
- Normalise Unicode (NFC), segment Vietnamese words with `pyvi` (ViTokenizer), lowercase and lightly clean each article
- Do a deterministic **stratified 70 / 15 / 15** split per category
- Write one `<category>.txt` per category (UTF-8, one doc per line) under `clean-data/train/`, `clean-data/val/`, and `clean-data/test/`

Expected output:
```
Splitting with ratio  train=70%  val=15%  test=15%
Category                   Total  Train    Val   Test
-------------------------------------------------------
  Chinh tri Xa hoi         12786   8950   1918   1918
  ...
  TOTAL                    84132  58893  12619  12620
```

---

### Step 2 — Train the model

```bash
python src/train.py
```

This will:
1. Load articles directly from `clean-data/train/` (~58.9k), `clean-data/val/` (~12.6k), and `clean-data/test/` (~12.6k).
3. Download `vinai/phobert-base-v2` from Hugging Face on the first run.
4. Fine-tune PhoBERT-base-v2 with AdamW, linear warmup, gradient clipping, and early stopping.
5. Save outputs to `phobert-v2/`:
   - `best_model/` — best checkpoint by lowest validation loss
   - `label_map.json` — category → integer mapping
   - `training_history.csv` — per-epoch metrics
   - `training_log.txt` — full training log
   - `confusion_matrix.png` — confusion matrix on the test set

#### Training arguments

All hyperparameters can be overridden via CLI flags:

| Flag | Default | Description |
|------|---------|-------------|
| `--epochs` | `10` | Maximum number of training epochs |
| `--batch_size` | `32` | Training batch size |
| `--eval_batch_size` | `64` | Evaluation batch size |
| `--max_len` | `256` | Maximum token sequence length |
| `--lr` | `1e-5` | AdamW learning rate |
| `--warmup_ratio` | `0.1` | Fraction of total steps used for linear warmup |
| `--patience` | `3` | Early stopping patience (epochs without val-loss improvement) |

**Example:**

```bash
python src/train.py --epochs 5 --batch_size 16 --lr 2e-5
```

---

### Step 3 — Run inference

`main.py` loads the best checkpoint from `phobert-v2/best_model/` and prints the top-3 predictions with confidence scores.

**Interactive mode** — prompts you to type or paste the article:

```bash
python src/main.py
# Enter news text: <type or paste your article here>
```

**CLI mode** — pass the text directly as arguments:

```bash
python src/main.py Đội tuyển Việt Nam thắng 2-0 trước Thái Lan tại SEA Games.
```

> **Tip:** For long articles or text containing special characters, use interactive mode or pipe from a file:
> ```bash
> cat article.txt | python src/main.py
> ```
